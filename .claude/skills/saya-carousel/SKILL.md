# ستايل كاروسيل سايا

القرارات من المستخدم (2026-10-13)، بعد 3 جولات أسئلة. **هالستايل بيغلب على القيم الافتراضية لمهارة `carousel-creator` وعلى الكاروسيلات القديمة** (`carousels/google-free-ai` و`carousels/chatgpt-codes`: كحلي غامق وفيها وجه، وما اتعتمدت).

القواعد العامة بتضل: `.claude/skills/carousel-creator` (RTL، فحص الجودة)، `quality-manager` قبل التسليم، وقواعد البيت بـ `CLAUDE.md`. لا تبني كاروسيل بدون طلب صريح.

## الأرقام والمقاس

- المقاس **1080×1440 (3:4)**.
- الخط: **Cairo** (الملفات بـ `video/public/fonts/cairo-*`). العنوان 900، والسطر 700. **ولا نص أقل من 40px.**
- أرقام غربية 1 2 3.
- الألوان:
  - سماوي فاتح للخلفية: تدرّج `#EAF6FF` ← `#CFEBFF` ← `#A9D9FF`
  - خطوط/رسوم غامقة: `#12356E` (أزرق غامق) و`#0B1B3F` (كحلي) للنص
  - تمييز: `#1E90FF` · كروت: `#FFFFFF` بظل `0 14px 40px rgba(11,27,63,.12)` · زوايا 40px
- الأيقونة: سماكة خط 6–8px، وتوهج `drop-shadow(0 0 14px rgba(30,144,255,.55))`.

## البنية (من carousel-creator، بتعديل الستايل)

1. **الغلاف:** هوك قوي (3–7 كلمات) + رسمة. اكتبه آخر شي. لازم يشتغل كمنشور لحاله.
2. **شريحة 2 = هوك تاني مستقل** (بتنفهم بلا الغلاف) + جملة شوق.
3. **الجسم:** كرت أبيض + أيقونة خطية + عنوان ~6 كلمات + سطر + جملة الشوق تحت.
4. **قبل الأخيرة (اختياري):** شريحة مشاركة («ابعتها لصاحبك اللي…»).
5. **الختام:** خلاصة بجملة + **CTA وحدة** (حفظ، أو إرسال، أو تعليق) + الـ handle أكبر شوي. بلا جملة شوق.
- المعلومة الأقوى بتنقال بالآخر، والهوك بيوعد فيها (قاعدة سايا).
- لا ادعاء عن أداة قبل التحقق، ولا أرقام مخترعة.

## طريقة البناء

HTML + Playwright (`export_slides.js` من مهارة cover-designer): ولّد الشرائح PNG، وارفعهم مع ورقة مراجعة (`tile=4x2`). الأيقونات SVG مرسومة بالـ stroke. افحص قبل التسليم: النص ما يطفح، والعربي سليم، وما في شي من القائمة الممنوعة تحت.
