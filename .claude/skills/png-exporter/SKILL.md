# PNG Exporter — مصنع المحتوى

## الهدف
تحويل سلايدات الكاروسيل من HTML إلى صور PNG عالية الدقة جاهزة للرفع على انستقرام.

## الطريقة المدمجة (الافتراضية)

كاروسيل مصنع المحتوى يحتوي بالفعل على زري التصدير:
- **"حفظ هذا السلايد PNG"** — يحفظ السلايد الحالي
- **"تصدير كل السلايدات PNG"** — يحفظ كل السلايدات بالترتيب

هذه الأزرار تعمل عبر مكتبة `html2canvas` بالإعدادات:
```javascript
html2canvas(slide, {
  scale: 2.5,        // جودة عالية
  width: slideWidth,
  height: slideHeight,
  backgroundColor: null,
  useCORS: true
})
```

## إذا طُلب تصدير خارجي

إذا أرسل المستخدم ملف HTML كاروسيل خارجي ويريد تصديره:

1. اقرأ الملف
2. تأكد أن html2canvas موجود، وإلا أضفه
3. تأكد أن أزرار التصدير موجودة، وإلا أضفها
4. احفظ الملف المعدّل وأعطِ المستخدم الرابط

## مواصفات الصورة
- الأبعاد: 1080×1350 بكسل (نسبة 4:5 — انستقرام)
- الجودة: PNG كاملة بدون ضغط
- اسم الملف: `slide-[رقم]-[اسم الحساب].png`
