# ستايلات المونتاج المحفوظة

إلى جانب `video-editor-bassam`، عند المستخدم **5 ستايلات مونتاج محفوظة** كمهارات داخل مشروع Remotion
بمستودع `ahmedalomar521-ui/saya` (مجلد `.claude/skills/`). **بتشتغل بس بجلسة Claude Code على هالمستودع**،
مش بالمحادثة العادية. إذا المستخدم بالمحادثة العادية وطلب ستايل منها، قلّه بسطر يفتح جلسة Claude Code على مستودع `saya`.

## القائمة

| الستايل | الشخصية | مناسب لـ | الكلمة اللي بتشغّله |
|---|---|---|---|
| **ستايل 0** | دمج كل الستايلات: يختار لكل جملة أنسب أداة، ومعه قواعد `video-editor-bassam` (معنى المشهد، ميزانية الأصوات، سجل يمنع التكرار، فحوص اللون والجودة) | **الافتراضي** لأغلب ريلز سايا، أفضل نتيجة | "بستايل 0" / "ستايل صفر" / "كل الستايلات" |
| **ستايل 1** | رسوميات كتير: شاشة مقسومة، عناوين صفرا بطبقتين، رسومات يد، كابشن صغير | شرح أدوات ومواقع وخطوات | "بستايل 1" |
| **ستايل 2** | الكابشن هو التصميم: كابشن أصفر كبير متوهج بكشيدة، كلمات حمرا، شاشات نعناعية وورقية | ريل كلامي بدو طاقة ونص قوي | "بستايل 2" |
| **ستايل 3** | بسيط: كلمة وحدة صغيرة تحت الذقن، تأكيدات قليلة، ومضات بيضا | نصيحة هادية، رأي، قصة قصيرة | "بستايل 3" |
| **ستايل 4** | استوديو غامق + رسوميات نيون فوق الراس، كلمات بيضا كبيرة، أرقام أقسام | تقنية، بيانات، تطبيقات، "أولاً/ثانياً" | "بستايل 4" |

## كيف تختار

```
المستخدم سمّى ستايل؟ ← هو.
ما سمّى:
  ريل عادي لسايا ← ستايل 0 (اقترحه بسطر)
  خطوات تطبيق / إعدادات ← ستايل 0 أو 1 (الشاشة المقسومة)
  محتوى هادي أو رأي ← ستايل 3
  أرقام / مقارنة أدوات / ذكاء اصطناعي ← ستايل 4 أو 0
  بدو مونتاج سريع بلا كود (قص + كابشن) ← video-editor-bassam بالوضع السريع
```

اقترح **ستايل واحد** مع سبب بجملة، ولا تعرض القائمة كاملة إلا إذا سأل.

## قواعد البيت (بتنطبق على كل الستايلات، ومحفوظة بـ`CLAUDE.md` بالمستودع)
- **لون الفيديو تقريباً بلا تعديل:** تشبع وتباين خفاف جداً بس. ممنوع أبيض وأسود، صبغات، تفتيح أو تغميق.
- **الكلمة المنطوقة بالكابشن لونها أزرق فاتح** (`#8FD3FF`) بكل الستايلات.
- **خط البيت Tahrir Bold** لكل النص العربي.
- **ما في مونتاج ولا رندر إلا بطلب صريح.** حفظ ستايل = حفظ بس.

## فحوصات الاحتفاظ (جزء من ستايل 0، وطبّقها على أي ستايل)
- أول فريم: العنوان والكلام من الفريم صفر، بلا صمت ولا ظهور بطيء.
- قبل الثانية 7 المشاهد بيعرف شو رح ياخد.
- ما في شي ثابت أكتر من ~5 ثواني (الوجه المعبّر لحد ~7).
- النص بيطلع بعد الكلمة بـ0.1–0.3 ثانية، مش قبلها.
- قطع حاد وزوم وومضة، بلا ذوبان (cross-dissolve) بين المشاهد.
- كل النص والرسوميات جوا المنطقة الآمنة (x 70–1010، y 150–1570 على 1080×1920).
- **فريم الغلاف:** وجه سايا + عنوان الهوك بالمربع اللي بالنص (1080×1080)، وأعطِ المستخدم توقيته ليختاره غلاف بإنستغرام.

## المدخلات اللي بيحتاجها أي ستايل
فيديو HeyGen السادة + ملف SRT من CapCut (نفس المرحلة 5 بخط الإنتاج). الناتج فيديو MP4 عمودي.
إذا الملف أكبر من 30 ميغا بينبعت نسخة مضغوطة، مع عرض الأصلي مقسوم لأجزاء.
