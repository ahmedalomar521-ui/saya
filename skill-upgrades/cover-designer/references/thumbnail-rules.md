# قواعد الغلاف والصورة المصغرة

## اختبار الإبهام (120 بكسل)

الصورة المصغرة بتنشاف أول مرة بعرض **~120 بكسل** على الجوال، وغلاف الريل بالشبكة نفس الشي تقريباً.
بهالحجم لازم يبين: **الشعور** (من الوجه والألوان)، **الموضوع** (من التكوين)، و**النص** إذا كان كبير كفاية.
صغّر الصورة ذهنياً (أو فعلياً) لـ120 بكسل. إذا صارت لطخة، أعد التصميم.

## الوجه

- الوجه ياخد **30–50٪** من مساحة الصورة المصغرة (يوتيوب)، وأقل شوي بغلاف الريل.
- **عيون سايا بتطلّع باتجاه النص أو العنصر** (مش للفراغ). العين بتوجّه عين المشاهد.
- التعبير حسب نوع المحتوى:

| التعبير | لمين |
|---|---|
| مفاجأة / دهشة | اكتشاف، ميزة مخفية، "ما كنت بعرف" |
| فضول (حاجب مرفوع) | شرح، كيف تعمل… |
| حماس | أداة جديدة، تحديث |
| قلق / تحذير | غلط شائع، خصوصية، "وقّف تعمل هيك" |
| ثقة (ابتسامة خفيفة) | نصيحة خبيرة، خلاصة |
| محايد | تجنّبه |

## النص

- **6 كلمات بالكتير** (يوتيوب)، **3–5 كلمات** (غلاف ريل).
- خط عريض جداً (خط البيت Tahrir Bold، نفس خط المونتاج)، مع حد أو ظل خفيف ليبين على أي خلفية.
- **لا تكرر العنوان.** إذا عنوان يوتيوب بيقول "5 إعدادات بالآيفون"، النص على الصورة يكون الشعور أو النتيجة ("بطارية أطول!") مش نفس الجملة.
- بلا نص أصلاً إذا الوجه والعنصر بيحكوا القصة لحالهم.

## الألوان

- **3 ألوان بالكتير** بالصورة.
- الخلفية والعنصر الرئيسي متعاكسين (غامق/فاتح، بارد/دافي). لوحة سايا جاهزة لهيك: **كحلي غامق + أزرق سماوي + لمسة أصفر عنبري** للنص أو السهم.
- لا تلزّق لونين من نفس الحرارة (أحمر على برتقالي = طين).

## المناطق الممنوعة

| الشكل | ابعد العناصر المهمة عن |
|---|---|
| يوتيوب 16:9 | الزاوية اليمين تحت (مدة الفيديو)، الزاوية اليسار تحت (شريط التقدم) |
| غلاف ريل 9:16 | أعلى ~150 بكسل وأسفل ~350 بكسل، وخلّي النص والوجه **بالمربع اللي بالنص** لأن الشبكة بتقصّ لـ3:4 أو 1:1 |
| كاروسيل 4:5 | ~70 بكسل من كل طرف، وشريط التقدم تحت |

## أنماط جاهزة حسب المحتوى

| المحتوى | التكوين |
|---|---|
| شرح / كيف | سايا يمين، لقطة الشاشة أو الأيقونة يسار، سهم أصفر بينهم |
| قبل/بعد | تقسيم بالنص: ❌ رمادي باهت ← ✅ ملوّن، سايا بالزاوية |
| مقارنة أداتين | أيقونتين كبار و"ضد" بالنص، سايا فوق أو تحت بتعبير حيرة |
| قائمة / رقم | رقم ضخم (5) + كلمة وحدة، سايا بتأشّر عليه |
| تحذير | سايا بتعبير قلق + إشارة ⚠️ أو ✋ + كلمة وحدة ("وقّف!") |

اعطِ **خيارين بفرق واحد واضح** (تعبير مختلف، أو خلفية مختلفة، أو مع/بلا نص)، مش صورتين مختلفتين بكل شي.
