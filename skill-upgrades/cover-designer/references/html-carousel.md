# بناء الكاروسيل بـHTML (عربي سليم 100٪)

مولّدات الصور بتغلط بالعربي. لهيك أفضل طريق للكاروسيل والأغلفة النصية هو:
**الصورة (سايا، الاستوديو، لقطة شاشة) من أداة التوليد بلا نص ← النص والتصميم بـHTML ← تصدير PNG.**

## متى تستعمله
- كاروسيل كامل (نص + أيقونات + لقطات شاشة).
- غلاف ريل أو صورة مصغرة فيها نص عربي، فوق صورة لسايا مولّدة **بلا نص**.
- إذا ما في بيئة بتشغّل كود (مثلاً المحادثة العادية بلا أدوات)، سلّم ملف HTML جاهز والمستخدم بيفتحه ويصوّره، أو ارجع لطريقة أوامر التوليد.

## الخطوات

1. **انسخ القالب** `assets/carousel-template.html` لمجلد الشغل، وانسخ جنبه `assets/fonts/` (خط Tahrir Bold).
2. **اكتب المحتوى أول** حسب `carousel-system.md` (الغلاف، الهوك الثاني، الجسم، الختام)، وخذ موافقة المستخدم عالنص.
3. **عبّي الشرائح:** كل شريحة `<section class="slide">`. الأنواع:
   - `brand`: تدرّج الهوية، للغلاف والختام.
   - بلا كلاس إضافي أو `alt`: كحلي، للجسم (بدّل بينهم للإيقاع).
   - `light`: بيج فاتح، شريحة وحدة أو اثنتين بالنص لكسر الرتابة.
   - كلمة وحدة مهمة بكل شريحة بـ`<span class="hot">`. **وحدة بس.**
   - مقارنة: `<div class="wrong">❌ …</div>` و`<div class="right">✅ …</div>`.
   - لقطة شاشة أو صورة لسايا: `<img class="shot" src="…">`.
4. **شريط التقدم وسهم السحب بينضافوا لحالهم** بالسكربت اللي بآخر القالب (ما في سهم على الأخيرة).
5. **صدّر:**
   ```bash
   node <skill>/scripts/export_slides.js carousel.html slides/
   ```
   بيطلّع `slide-01.png`… بمقاس 1080×1350. للأغلفة: `… cover/ 1080 1920` (ريل) أو `… thumb/ 1280 720` (يوتيوب).
   بيحتاج Playwright (`npm i -D playwright`). إذا في Chromium جاهز بالجهاز: `CHROMIUM_PATH=/path/to/chrome`.
6. **اعمل ورقة مراجعة** (كل الشرائح جنب بعض بصورة وحدة) وشوفها قبل التسليم:
   ```bash
   ffmpeg -i slides/slide-%02d.png -filter_complex tile=5x2 -frames:v 1 sheet.png
   ```
   افحص: الخط Tahrir طالع (مش خط النظام)، ما في نص طالع برا الإطار أو فوق شريط التقدم، كلمة `hot` وحدة بكل شريحة، والتناوب الفاتح/الغامق مريح.

## قواعد التصميم
- **الهوية بمكان واحد:** الألوان بمتغيرات `:root` بأول القالب. إذا تغيرت هوية سايا، بتتغير هناك بس.
- النص العربي `dir="rtl"`، والأرقام والإنجليزي بيرجعوا لخط لاتيني تلقائياً (Tahrir عربي بس).
- **الحجوم الدنيا:** العنوان 84 بكسل، النص 44 بكسل. أصغر من هيك ما بينقرا بالجوال.
- الهامش 72 بكسل، وما في محتوى بآخر 140 بكسل (مكان شريط التقدم).
- ممنوع تحط وجه سايا والنص فوق بعض. الوجه بنص، والنص فوقه أو جنبه.
- إذا المستخدم بعت لقطة شاشة، افحص نوعها الحقيقي (`file`) قبل ما تحطها، لأن الامتداد أحياناً بيكذب.
